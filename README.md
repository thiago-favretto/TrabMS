# Sistema Interativo em Python com Pygame

## Descrição
Este projeto foi desenvolvido como trabalho acadêmico para a disciplina de Linguagem de Programação Aplicada no curso de Análise e Desenvolvimento de Sistemas. O sistema é uma aplicação interativa que utiliza a biblioteca Pygame para criar uma experiência dinâmica, aplicando conceitos fundamentais de **Programação Orientada a Objetos (POO)** e **lógica de programação**.

O projeto simula um jogo 2D com naves e score, com foco no gerenciamento de estados, colisões e interação com o usuário.

## Tecnologias Utilizadas
- **Python 3** (Linguagem principal)
- **Pygame** (Biblioteca para criação de jogos e aplicações multimídia)
